# Kit de Herramientas VBA para Excel

Repositorio modular para la automatización, gestión de datos y control de flujos de trabajo en Excel mediante VBA.

## Arquitectura de Módulos
- **E/S y Archivos:** `modArchivos`
- **Interfaces y Formularios:** `modBuscador`, `modfrmprogreso`
- **Consultas y Datos:** `modBusquedas`, `modRangoUtils`, `modGeneradores`
- **Control y Núcleo:** `modControlador`, `modDispatcher`, `modprojecto`, `modSesion`
- **Infraestructura:** `modConstantes`, `modprueba`
